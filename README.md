Minecraft Skript plugin and scripts largely inspired by RootCellar's work: https://github.com/RootCellar

These are scripts designed to give Minecraft an RPG feel with elements like classes, levels, advanced monsters, spells, and other special features typically found in RPG games. This is based off of the 1.18.2 version of Minecraft and various supporting plugins of the time.

After cooperating on the scripts together, I will now manage and update them myself as of his passing.

Note: This version is now outdated, and I am continuing work on a far newer version of Minecraft with new and different plugins. You can find this at the Modern-Version branch.
